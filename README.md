# HR Dashboard Analytics #

## Project Overview

This project focuses on analyzing employee performance and workforce data using Power BI. The objective is to build an interactive HR dashboard that helps HR teams understand employee performance, promotions, attendance, salaries, and departmental trends. The dashboard allows users to filter data dynamically and gain meaningful business insights for better decision-making.

---

## Objectives

- Analyze employee performance across different departments.
- Monitor promotion rates and employee distribution.
- Compare average salaries across job roles.
- Understand employee attendance and performance trends.
- Build an interactive dashboard for HR reporting.

---

## Tools Used

- Microsoft Power BI
- Microsoft Excel
- DAX

---

## Dataset Information

- Rows: 10,000
- Columns: 25
- Domain: Human Resources (HR)

---

## Key Performance Indicators (KPIs)

- Total Employees
- Average Salary
- Average Attendance
- Average Performance Score
- Promotion Rate
- Average Job Satisfaction

---

## Dashboard Features

- Department-wise Performance Analysis
- Employee Distribution by Department
- Salary Analysis by Job Role
- Performance Category Distribution
- Promotion Status Analysis
- Performance Trend by Experience Level

### Interactive Filters

- Department
- Gender
- Experience Level
- Performance Category

---

## Business Insights

- The organization has a strong overall employee performance level, with most employees falling into higher performance categories.
- Promotion rates indicate that employees are receiving growth opportunities within the organization.
- Employees with more experience generally show better performance scores.
- Salary distribution across job roles helps identify compensation patterns.
- Attendance levels remain consistently high, showing good employee engagement.
- Interactive filters make it easy to analyze HR metrics across different departments and employee groups.
